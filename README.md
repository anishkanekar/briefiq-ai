# BriefIQ AI

AI-Powered Meeting Intelligence for Sales Teams

## Overview

BriefIQ AI automatically analyzes upcoming meetings from Google Calendar, researches attendees and companies, identifies strategic business signals, and generates executive-level sales briefings delivered through Slack.

## Features

- Google Calendar Integration
- AI Meeting Research
- Company Intelligence
- Stakeholder Intelligence
- Strategic Signal Detection
- Executive Brief Generation
- Slack Delivery

## Tech Stack

- n8n
- Groq LLM
- Serper API
- Google Calendar API
- Slack API
- Docker

## Workflow

Google Calendar
→ Meeting Detection
→ Company Research
→ AI Analysis
→ Executive Brief
→ Slack Delivery
